# 数学建模

课程算法练习、课程作业与南京工业大学相关赛训材料。默认工作分支是 **`stu`**。

远程：https://github.com/luyushu-shu/shuxuejianmo （Private）

国赛 A 题药材烘干不在本库，见 https://github.com/luyushu-shu/cumcm-2026-a 。笔记入口在知识库 https://github.com/luyushu-shu/obsidian-vault 。

## 克隆

本机访问 `github.com` 的 HTTPS 容易失败，使用 SSH：

```bash
git clone -b stu git@github.com:luyushu-shu/shuxuejianmo.git
```

论文类作业一般用 XeLaTeX 编译对应目录下的 `main.tex`。校赛 / 答题模板在：

- `作业/南京工业大学数学建模校赛论文/`
- `作业/答题模版latex和word版各一份。/`

`ECNU2NJTECH/` 里是字体安装与模板迁移说明（先装 `STZHONGS` 再 XeLaTeX）。
