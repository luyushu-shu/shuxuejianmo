## 1. 多元线性回归基础

### 1.1 基本概念
- 定义：研究多个自变量（X₁, X₂, ..., Xₖ）与一个因变量（Y）之间线性关系的统计方法
- 数学模型：Y = β₀ + β₁X₁ + β₂X₂ + ... + βₖXₖ + ε
  - β₀：截距项
  - βᵢ：第i个自变量的偏回归系数
  - ε：随机误差项

### 1.2 基本假设
- 线性性：变量间存在线性关系
- 独立性：观测值之间相互独立
- 同方差性：误差项具有相同方差
- 正态性：误差项服从正态分布
- 无多重共线性：自变量之间不存在完全线性相关

### 1.3 与一元线性回归的区别
- 自变量数量不同
- 参数解释不同
- 计算复杂度不同
- 模型诊断更复杂

## 2. 参数估计

### 2.1 矩阵表示
- Y = Xβ + ε
  - Y：n×1因变量向量
  - X：n×(k+1)设计矩阵
  - β：(k+1)×1参数向量
  - ε：n×1误差向量

### 2.2 最小二乘估计
- 目标函数：min Σ(yi - β₀ - β₁x₁ᵢ - ... - βₖxₖᵢ)²
- 矩阵形式解：β̂ = (X'X)⁻¹X'Y
- 参数估计的统计性质
  - 无偏性
  - 有效性
  - 一致性

### 2.3 偏回归系数解释
- βᵢ：在其他自变量固定时，Xᵢ变动一个单位，Y的平均变动量
- 标准化回归系数：便于比较不同自变量的相对重要性

## 3. 模型评估

### 3.1 拟合优度
- 多重相关系数（R）
  - 定义：Y与所有自变量的综合相关程度
  - 计算：R = √(1 - SSE/SST)

- 决定系数（R²）
  - 定义：模型解释的变异比例
  - 计算：R² = 1 - SSE/SST

- 调整R²
  - 定义：考虑自变量数量的修正R²
  - 计算：R²ₐ = 1 - (1-R²)(n-1)/(n-k-1)

### 3.2 显著性检验
- F检验
  - 原假设：所有回归系数为0
  - F统计量：MSR/MSE
  - 判断标准：p值

- t检验
  - 检验单个回归系数的显著性
  - t统计量：βᵢ/SE(βᵢ)

### 3.3 预测评估
- MSE（均方误差）
- RMSE（均方根误差）
- MAE（平均绝对误差）

## 4. 变量选择

### 4.1 向前选择法
- 步骤：
  1. 从空模型开始
  2. 逐个添加最显著的变量
  3. 直到没有显著变量可添加
- 优点：计算简单
- 缺点：可能忽略变量组合效应

### 4.2 向后剔除法
- 步骤：
  1. 从全模型开始
  2. 逐个删除最不显著的变量
  3. 直到所有变量都显著
- 优点：考虑所有变量
- 缺点：计算量大

### 4.3 逐步回归法
- 结合向前和向后方法
- 每步都考虑添加和删除变量
- 更可能找到最优模型

### 4.4 信息准则
- AIC（赤池信息准则）
- BIC（贝叶斯信息准则）
- 权衡模型复杂度和拟合优度

## 作业答案

### 1. 一元线性回归和多元线性回归的比较

相同点：
- 都是研究因变量与自变量之间的线性关系
- 都使用最小二乘法估计参数
- 都需要满足基本假设（如线性性、独立性等）

不同点：
- 自变量数量：一元只有一个，多元有多个
- 计算复杂度：多元回归计算更复杂
- 参数解释：多元回归中为偏回归系数
- 模型诊断：多元回归需要额外考虑多重共线性

优势：
- 可以同时考虑多个影响因素
- 预测精度通常更高
- 更符合实际问题的复杂性

局限性：
- 可能存在多重共线性问题
- 参数估计和解释更复杂
- 需要更多的样本量

### 2. 多重共线性问题

定义：
- 自变量之间存在强相关关系
- 导致参数估计不稳定
- 影响模型的解释能力

检测方法：
1. 相关系数矩阵
   - 观察自变量间的相关系数
   - |r| > 0.8表示可能存在多重共线性

2. VIF（方差膨胀因子）
   - VIF = 1/(1-R²)
   - VIF > 10表示严重多重共线性

3. 条件数
   - 特征值之比
   - 大于30表示存在多重共线性

处理方法：
1. 删除高度相关变量
2. 主成分分析（PCA）
3. 岭回归等正则化方法
4. 收集更多数据

### 3. 变量选择方法比较

1. 向前选择法
- 优点：
  - 计算量小
  - 适合自变量较多的情况
  - 容易实现
- 缺点：
  - 可能忽略变量间的交互作用
  - 不能保证得到最优模型

2. 向后剔除法
- 优点：
  - 考虑了所有变量的影响
  - 更容易保留重要变量
- 缺点：
  - 计算量大
  - 不适合自变量很多的情况

3. 逐步回归法
- 优点：
  - 结合了前两种方法的优点
  - 更可能找到最优模型
  - 考虑变量间的相互影响
- 缺点：
  - 计算量最大
  - 可能受初始模型影响
  - 可能陷入局部最优
